# Medical Data Analysis | MySQL

## Overview
This is a SQL project on a sample hospital database. I wrote queries to answer practical questions about patients, admissions and doctors.

## Database Tables
- patients
- admissions
- doctors
- province_names

## What I Did
- Found patients by gender, name pattern, weight and height range.
- Counted patients by city and admissions by day of the month.
- Found patients admitted more than once for the same diagnosis.
- Joined tables to link patients with their diagnosis and their doctor's specialty.
- Grouped patients into weight groups and marked obesity as 0 or 1.
- Updated missing allergy values to 'NKA' and formatted full names.

## Example Questions Solved
- Show unique first names that occur only once.
- Show the number of patients in each city, from most to least.
- Show patients with Epilepsy whose doctor's first name is Lisa.
- Show the difference between the largest and smallest weight for one last name.

## Topics Covered
Filtering, sorting, grouping, joins, UNION, CASE, string and date functions, UPDATE.
